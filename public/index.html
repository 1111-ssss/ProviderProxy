Provider Proxy

Собери устойчивые цепочки моделей и переключайся между провайдерами без ручного редактирования конфигов.

работает локально

1 · Провайдеры

Ключ и адрес API (OpenAI-совместимый). «Чекин» — открыть checkin-страницу, если она задана. Модели провайдера выбираются в шаге 2.

2 · Модели провайдеров

Отметь галочками модели, которые есть у провайдера, — они сохраняются локально, и из них собираются цепочки в шаге 3. Список берётся с его /v1/models и из сохранённых; отсутствующую модель можно вписать вручную.

провайдер:

3 · Цепочки моделей

Каждая цепочка — это один ID модели для OpenCode и понятный порядок запасных провайдеров. Если первый не отвечает, запрос автоматически идёт дальше по списку.

4 · Логи

Живой хвост вывода прокси. Держится в памяти и чистится само — старые строки вытесняются новыми.

—

5 · Usage

Счётчики живут в памяти прокси и обнуляются при его перезапуске. Токены видны, когда upstream их присылает.
