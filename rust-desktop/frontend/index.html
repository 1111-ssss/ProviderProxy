Модель по умолчанию для skill

Провайдер и модель, которые skill генерации изображений использует по умолчанию: и на вкладке изображений, и при запуске skill, если в задаче не указана другая модель.

Модель по умолчанию

Эта модель выбирается на вкладке изображений при открытии приложения и используется, когда skill запускается без явной модели.

Токен доступа

Прокси защищён токеном (authToken). Введите его, чтобы открыть интерфейс. Токен хранится в настройках прокси и уже есть у того, кто его включал.
