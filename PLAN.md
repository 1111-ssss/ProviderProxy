## 0. Целевая структура (решение владельца)

**Один бэкенд — Rust/Tauri.** Node-версия удаляется целиком. Rust уже поднимает
HTTP-сервер и отдаёт GUI, поэтому и окно приложения (WebView), и обычный браузер
на `http://127.0.0.1:8787/` получают один и тот же интерфейс из одного бэкенда.
npm и сборщик не нужны: встраивание файлов делает `include_str!`.

```
frontend/                ЕДИНСТВЕННЫЙ интерфейс (раньше — две разъехавшиеся копии)
  index.html             каркас: <head>, <link>, разметка вкладок, <script src> по порядку
  css/*.css              токены/тема, база, компоненты, страницы
  js/*.js                обычные скрипты по порядку, общая область видимости (без import/export)

rust-desktop/src/
  main.rs                только запуск Tauri + регистрация команд
  platform/autostart.rs  autostart и трей
  platform/shortcut.rs   ярлыки Windows/Linux
  updater.rs             обновление/откат
  proxy/                 HTTP-бэкенд (не зависит от Tauri)
    assets.rs            отдача frontend/* (include_str! + маршруты)
    handlers/            HTTP-обработчики, разбитые по областям
```

Удаляется: `server.mjs`, `public/`, `test.mjs`, `launch.sh`, `launch-windows.ps1`,
`release.ps1`, Node-часть релизного workflow. История остаётся в git.

## 1. Багфиксы (приоритет)

- [ ] **Б1. Приложение открывается снова после закрытия (Windows).**
      Причина-кандидат: закрытие окна прячет его в трей, процесс остаётся; повторный
      запуск поднимает второе окно/процесс. Надёжно: перед стартом гарантированно
      вытеснять прошлый процесс, а при отсутствии трей-иконки закрывать по-настоящему.
- [ ] **Б2. Повторный запуск: убить старый процесс и запустить новый.**
      `shutdown_running_instance` уже есть; сделать его надёжным: ждать освобождения
      порта, не паниковать при занятом порте (сейчас `.expect` убивает окно молча).
- [ ] **Б3. Полоска загрузки обновления + вынести кнопку в меню вкладок над «Настройками».**
      Сейчас кнопки нет (только баннер в настройках, статичный текст). Добавить
      реальный прогресс (Rust отдаёт `(скачано, всего)`), пункт меню появляется
      только когда на��лось обновление, там же полоса прогресса.
- [ ] **Б4. Откат: гасить автообновление; уведомлять только по ручной проверке
      или если вышла версия выше, с которой откатились.**
      «Потолок» = версия, с которой пользователь откатился; не показывать баннер и не
      авто-ставить ниже потолка.
